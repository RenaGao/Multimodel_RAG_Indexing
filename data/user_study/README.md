# User-study responses

`user_study_anonymized.xlsx` contains feedback from five volunteers who evaluated the shopping systems through a web interface. They were recruited through the authors' personal contacts and received no payment.

Each row is one participant. The file retains five consecutive blocks of six questions: overall satisfaction, four statements about interaction quality, and an open comment. The final three questions ask about overall system preference, perceived personalization, and the overall experience. Question wording, block order, response values, and written comments are preserved from the form export, including numeric satisfaction ratings and text agreement responses. Repeated question headings retain the export's numeric suffixes; these suffixes identify question blocks, not system names.

Original response IDs, names, email addresses, and start, completion, and modification times were removed. Rows were shuffled and assigned IDs P01–P05. No identity mapping is included. The workbook was rebuilt without source document properties, custom properties, or printer settings.

This file records the interactive user study. It does not establish the number of annotators in the separate dialogue-rating check described in the paper.
